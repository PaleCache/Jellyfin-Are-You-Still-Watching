# 🚀 Jellyfin Are You Still Watching?
Simple are you still watching like netflix (scuffed version) that uses jellyfins api to pause a users video during active hours, Works on all devices that an admin can control
## ℹ️ How to Use
- You need nodejs and npm installed, then in the project folder type npm install
- Edit the index.js and add you server's ip, and edit it to your needs including api key etc
- To run it type node .
- When a user starts watching you should see some debug in the console
